## Partie A — Cahier des charges principal (§1 à §35)

<!-- DÉBUT TEXTE ORIGINAL A -->
CONCEPTION D’UN JEU VIDÉO AAA DE COMBAT AFRICAIN ULTRA-RÉALISTE

Créer une nouvelle propriété intellectuelle (IP) de jeu vidéo de combat AAA, totalement originale, destinée aux consoles et PC de nouvelle génération.

Le jeu doit combiner la profondeur technique des grands jeux de combat modernes, la mise en scène cinématographique des jeux d’action AAA et un univers original fortement inspiré de l’Afrique dans ses paysages, ses architectures, ses traditions visuelles, ses sonorités, ses matières, ses mythologies et ses cultures.

IMPORTANT : ne copier aucun personnage, costume, pouvoir, architecture, musique, logo, scénario ou élément identifiable provenant d’une franchise existante.

Les références comme God of War, Tekken, Mortal Kombat, Street Fighter, Devil May Cry, BlazBlue, Persona Arena, Under Night In-Birth et autres jeux de combat doivent uniquement servir à comprendre les standards de qualité, de profondeur et de mise en scène recherchés.

L’objectif est de créer quelque chose qui puisse être immédiatement reconnu comme une nouvelle grande franchise africaine AAA, et non comme une copie d’une franchise existante.

⸻

1. IDENTITÉ DU JEU

Créer un jeu mélangeant :

* combat 1 contre 1 extrêmement technique ;
* action-aventure ;
* exploration ;
* narration cinématographique ;
* pouvoirs surnaturels ;
* armes ;
* arts martiaux ;
* progression des personnages ;
* tournoi ;
* affrontements contre des boss ;
* environnement interactif ;
* dégâts persistants.

Le jeu doit être :

ULTRA-RÉALISTE — CINÉMATOGRAPHIQUE — IMMERSIF — SOMBRE PAR MOMENTS — SPECTACULAIRE — PHYSIQUEMENT COHÉRENT — CULTURELLEMENT RICHE — AAA.

Le joueur doit avoir la sensation d’entrer dans un véritable monde vivant.

⸻

2. UNIVERS ORIGINAL

Créer un univers fantastique original inspiré de plusieurs imaginaires africains sans reproduire directement une religion, une ethnie ou une mythologie particulière.

L’univers doit mélanger :

* civilisations anciennes ;
* royaumes oubliés ;
* cités modernes ;
* villages ;
* forêts tropicales ;
* savanes ;
* montagnes ;
* déserts ;
* fleuves ;
* marécages ;
* temples ;
* sanctuaires ;
* palais ;
* ruines ;
* villes contemporaines ;
* territoires spirituels.

L’Afrique ne doit pas être représentée comme un simple décor exotique.

Elle doit être au cœur de l’identité du monde.

Les architectures, vêtements, armes, symboles, matériaux, musiques, langues, paysages et traditions doivent contribuer à construire une civilisation fictive crédible.

⸻

3. MYTHOLOGIE ORIGINALE

Créer une mythologie propre au jeu.

Les pouvoirs, créatures, clans, artefacts et phénomènes surnaturels doivent appartenir à l’univers du jeu.

Ne pas simplement reprendre les dieux ou figures mythologiques réelles.

Créer plutôt de nouveaux concepts inspirés de principes tels que :

* ancestralité ;
* mémoire ;
* énergie spirituelle ;
* forces naturelles ;
* ombre ;
* lumière ;
* feu ;
* eau ;
* terre ;
* vent ;
* foudre ;
* métal ;
* vie ;
* mort ;
* destin ;
* temps.

Les joueurs doivent progressivement découvrir que le monde visible n’est qu’une partie d’une réalité beaucoup plus vaste.

⸻

4. PERSONNAGES

Créer un roster initial de 20 à 30 combattants, chacun possédant une identité complète.

Chaque combattant doit avoir :

* nom ;
* origine ;
* histoire ;
* personnalité ;
* motivation ;
* philosophie ;
* style de combat ;
* morphologie ;
* costume ;
* équipement ;
* arme éventuelle ;
* pouvoir ;
* faiblesse ;
* capacité spéciale ;
* capacité ultime ;
* thème musical ;
* animations uniques ;
* expressions faciales ;
* rivalités ;
* dialogues spécifiques ;
* introduction ;
* animation de victoire ;
* animation de défaite.

Les personnages doivent représenter différentes régions et cultures fictives de l’univers.

Aucun personnage ne doit être un simple cliché.

⸻

5. DESIGN PHYSIQUE DES PERSONNAGES

Créer des humains photoréalistes.

Utiliser :

* anatomie crédible ;
* proportions réalistes ;
* muscles adaptés au style de combat ;
* peau avec pores ;
* imperfections naturelles ;
* cicatrices ;
* transpiration ;
* cheveux physiquement simulés ;
* pilosité réaliste ;
* yeux extrêmement détaillés ;
* dents réalistes ;
* expressions faciales complexes.

Les vêtements doivent posséder :

* coutures ;
* plis ;
* fibres ;
* poussière ;
* humidité ;
* déchirures ;
* usure ;
* salissures.

Les personnages ne doivent jamais avoir l’apparence de mannequins 3D génériques.

⸻

6. SYSTÈME DE COMBAT

Créer un système de combat hybride combinant :

* arts martiaux ;
* corps à corps ;
* armes blanches ;
* armes lourdes ;
* armes improvisées ;
* pouvoirs surnaturels ;
* esquives ;
* parades ;
* contres ;
* projections ;
* prises ;
* attaques aériennes ;
* attaques chargées ;
* combos ;
* attaques contextuelles ;
* finishers ;
* capacités ultimes.

Le système doit être :

simple à comprendre, difficile à maîtriser et extrêmement profond.

Chaque combattant possède une philosophie de combat différente.

⸻

7. PHYSIQUE RÉALISTE

Le corps doit avoir du poids.

Chaque mouvement doit respecter :

* gravité ;
* inertie ;
* centre de gravité ;
* accélération ;
* décélération ;
* transfert de poids ;
* friction ;
* collision ;
* équilibre.

Un personnage lourd ne doit pas réagir comme un personnage léger.

Un coup puissant doit réellement déplacer le corps.

Les personnages ne doivent jamais donner l’impression de glisser sur le sol.

⸻

8. SYSTÈME DE DÉGÂTS PERSISTANTS

RÈGLE FONDAMENTALE : CHAQUE IMPACT DOIT LAISSER UNE CONSÉQUENCE.

Les dégâts ne doivent jamais être uniquement une animation temporaire.

Le jeu doit conserver l’état réel du combattant pendant le combat.

Une armure :

intacte → fissurée → déformée → fortement endommagée → brisée.

Une arme :

intacte → endommagée → fissurée → déformée → cassée.

Un vêtement :

intact → sale → déchiré → fortement endommagé.

Une blessure :

impact → blessure → saignement → diminution du saignement → trace résiduelle.

Aucun reset automatique.

⸻

9. RÈGLES DE PRIORITÉ DES DÉGÂTS

Créer un système appelé :

DAMAGE PRIORITY & RESOLUTION SYSTEM

Chaque impact doit être calculé selon l’ordre suivant :

ÉTAPE 1 — LOCALISATION

Déterminer exactement ce qui est touché :

1. arme ;
2. bouclier ;
3. casque ;
4. armure ;
5. équipement ;
6. vêtements ;
7. peau ;
8. zone corporelle.

ÉTAPE 2 — OBSTACLE

Identifier les éléments situés entre l’attaque et le corps.

Exemple :

Épée → armure → vêtement → corps.

ÉTAPE 3 — MATÉRIAU

Calculer la résistance du matériau.

ÉTAPE 4 — ÉTAT PRÉEXISTANT

Une armure déjà fissurée doit être plus vulnérable qu’une armure intacte.

ÉTAPE 5 — ABSORPTION

Calculer la quantité d’énergie absorbée.

ÉTAPE 6 — TRANSMISSION

Calculer l’énergie restante transmise au corps.

ÉTAPE 7 — DOMMAGE

Déterminer le type et la gravité du dommage.

ÉTAPE 8 — BLESSURE

Créer une blessure correspondant à l’impact.

ÉTAPE 9 — SAIGNEMENT

Calculer le niveau de saignement.

ÉTAPE 10 — CONSÉQUENCE

Modifier éventuellement :

* posture ;
* mobilité ;
* endurance ;
* animations ;
* utilisation des armes ;
* comportement.

ÉTAPE 11 — PERSISTANCE

Conserver toutes les conséquences visuelles et physiques.

⸻

10. ARMURES

Chaque pièce d’armure doit posséder sa propre intégrité.

Exemple :

100 % : intacte

75 % : légèrement endommagée

50 % : fortement endommagée

25 % : état critique

0 % : détruite

Les valeurs peuvent varier selon le matériau.

Une pièce détruite ne doit jamais réapparaître pendant le combat.

⸻

11. ZONES VULNÉRABLES

Les protections doivent posséder différentes résistances.

Exemple :

CASQUE

* front : très résistant ;
* côtés : résistance intermédiaire ;
* visière : vulnérabilité spécifique ;
* attaches : vulnérabilité élevée.

ARMURE

* plastron : protection élevée ;
* épaules : protection intermédiaire ;
* articulations : protection réduite ;
* attaches : vulnérabilité élevée.

Le joueur expérimenté doit pouvoir exploiter les faiblesses de l’équipement adverse.

⸻

12. DESTRUCTION DES ARMES

Les armes doivent avoir leur propre intégrité physique.

Elles peuvent :

* se fissurer ;
* se déformer ;
* perdre une partie ;
* devenir moins efficaces ;
* se casser ;
* tomber ;
* être abandonnées.

Une arme cassée reste cassée.

Si une épée perd sa lame, le personnage ne doit jamais continuer à utiliser une épée visuellement intacte.

⸻

13. ARMES CONTRE ARMES

Lorsqu’une arme rencontre une autre arme, calculer :

* masse ;
* matériau ;
* vitesse ;
* angle ;
* dureté ;
* état ;
* force de l’impact.

Une arme déjà fragilisée doit avoir une probabilité beaucoup plus élevée de se casser.

⸻

14. BLESSURES

Les blessures doivent apparaître à l’endroit exact de l’impact.

Éviter les blessures générées aléatoirement.

Types possibles :

* coupure ;
* contusion ;
* abrasion ;
* ecchymose ;
* blessure superficielle ;
* blessure plus importante.

Les blessures doivent influencer progressivement le comportement du personnage.

⸻

15. SYSTÈME DE SAIGNEMENT RÉALISTE

Le sang doit être rendu avec un niveau de réalisme cinématographique.

Le système doit prendre en compte :

* localisation ;
* gravité ;
* mouvement ;
* posture ;
* temps ;
* vêtements ;
* environnement ;
* pluie ;
* eau ;
* gravité.

Lorsqu’une blessure importante survient :

IMPACT → SAIGNEMENT INITIAL → ÉCOULEMENT → DIMINUTION → TRACE RÉSIDUELLE.

Le saignement peut être important immédiatement après une blessure puis diminuer progressivement lorsqu’il n’y a pas de nouvelle aggravation.

Le sang doit pouvoir :

* couler sur la peau ;
* traverser les plis des vêtements ;
* tacher l’armure ;
* tomber au sol ;
* laisser des traces ;
* se mélanger à l’eau ;
* être progressivement dilué par la pluie.

Une nouvelle attaque sur une blessure existante peut modifier son état.

⸻

16. FATIGUE

La fatigue doit augmenter progressivement.

Le personnage doit :

* respirer plus fortement ;
* transpirer ;
* ralentir légèrement ;
* récupérer plus difficilement ;
* modifier sa posture ;
* devenir plus prudent ;
* montrer des signes de douleur.

La fatigue doit être visible sans devenir artificiellement frustrante.

⸻

17. ENVIRONNEMENT DESTRUCTIBLE

Les dégâts doivent également modifier l’environnement.

Un mur détruit reste détruit.

Une vitre cassée reste cassée.

Une colonne brisée reste brisée.

Le sol fissuré reste fissuré.

La végétation endommagée reste endommagée.

Les débris doivent rester présents selon les capacités techniques du système.

L’arène doit raconter visuellement le déroulement du combat.

⸻

18. PERSISTANCE DURANT UN TOURNOI

Le tournoi doit utiliser un système de continuité.

Exemple :

COMBAT 1

Armure légèrement endommagée.

COMBAT 2

L’armure reste endommagée.

COMBAT 3

Une pièce déjà fissurée se brise.

COMBAT 4

Le combattant arrive avec cette pièce toujours absente.

Les blessures, vêtements endommagés, armes détruites et autres conséquences doivent être conservés selon les règles du mode.

Le joueur doit avoir l’impression de suivre un véritable combattant à travers une compétition, et non de recommencer une nouvelle partie après chaque victoire.

La réparation doit être une mécanique réelle :

* atelier ;
* réparation ;
* soins ;
* repos ;
* remplacement d’équipement ;
* objet consommable ;
* phase narrative.

⸻

Mais ces conséquences doivent être progressives.

Une petite blessure ne doit pas rendre instantanément le personnage incapable de combattre.

## Partie B — Spécification du Damage Priority & Resolution System (§32 à §48)

<!-- DÉBUT TEXTE ORIGINAL B -->
32. SYSTÈME DE PRIORITÉ DES DÉGÂTS

Créer un Damage Priority & Resolution System chargé de déterminer précisément ce qui se produit lors de chaque impact.

Le système doit calculer les conséquences d’une attaque selon une hiérarchie stricte.

PRINCIPE ABSOLU :

Un impact doit être résolu de l’extérieur vers l’intérieur, de l’objet touché vers le corps, puis du dommage immédiat vers ses conséquences persistantes.

ORDRE DE PRIORITÉ

PRIORITÉ 1 — LOCALISATION DE L’IMPACT

Identifier précisément la zone touchée :

1. arme ;
2. bouclier ;
3. casque ;
4. armure ;
5. équipement secondaire ;
6. vêtements ;
7. peau ;
8. zone corporelle sous-jacente.

Le système doit utiliser la géométrie réelle du personnage et de son équipement afin de déterminer quelle surface a effectivement reçu le coup.

⸻

PRIORITÉ 2 — OBJET INTERPOSÉ

Si une protection se trouve entre l’attaque et le corps, elle doit être prise en compte avant d’appliquer les dégâts corporels.

Exemple :

Épée → plastron → torse

Le système calcule d’abord les dégâts sur le plastron.

Il ne doit pas appliquer automatiquement les mêmes dégâts directement au torse.

⸻

PRIORITÉ 3 — RÉSISTANCE DU MATÉRIAU

Déterminer la résistance du matériau frappé.

Exemples :

* tissu ;
* cuir ;
* bois ;
* verre ;
* métal léger ;
* métal lourd ;
* matériau composite ;
* pierre ;
* matériau surnaturel.

Comparer :

Force de l’impact × type d’attaque × angle d’impact

avec :

Résistance du matériau + état actuel de l’objet.

⸻

PRIORITÉ 4 — ÉTAT PRÉEXISTANT

Toujours prendre en compte les dégâts précédents.

Une pièce déjà fissurée doit être plus vulnérable qu’une pièce intacte.

Exemple :

Armure intacte → impact → fissure

puis :

nouvel impact sur la fissure → aggravation

puis :

nouvel impact suffisamment puissant → rupture

Ne jamais traiter chaque attaque comme si l’objet était neuf.

⸻

33. TRANSMISSION DES DÉGÂTS

Lorsqu’une protection absorbe un impact, une partie de l’énergie peut être transmise au corps.

Le système doit donc calculer :

Énergie de l’attaque → absorption de l’armure → énergie résiduelle → dommage corporel.

Une armure efficace réduit les dégâts mais ne transforme pas automatiquement un impact violent en absence totale de conséquence.

Le personnage peut subir :

* recul ;
* perte d’équilibre ;
* contusion ;
* fatigue ;
* douleur ;
* dommage interne simulé de manière abstraite pour le gameplay.

⸻

34. PRIORITÉ SELON LE TYPE D’ATTAQUE

Les différents types d’attaques doivent produire des conséquences différentes.

Attaque tranchante :
priorité à la pénétration ou à la coupure des matériaux vulnérables.

Attaque contondante :
priorité à la déformation, au recul, à la perte d’équilibre et à la transmission d’énergie.

Attaque perforante :
priorité à la pénétration d’une zone localisée.

Attaque lourde :
priorité à la destruction ou déformation de l’équipement.

Attaque explosive :
priorité aux dégâts de zone, aux projections et aux dégâts environnementaux.

Attaque élémentaire :
prendre en compte les propriétés du matériau et les conditions environnementales.

⸻

35. PRIORITÉ DES PROTECTIONS

Lorsqu’une attaque frappe plusieurs protections successivement, appliquer la résolution dans l’ordre physique réel.

Exemple :

arme → bouclier → armure → vêtement → corps

Chaque couche doit absorber, transmettre ou modifier l’énergie avant de passer à la suivante.

Si une couche est détruite pendant l’impact, la suivante peut recevoir une quantité d’énergie supérieure.

⸻

36. PRIORITÉ DES ARMURES ENDOMMAGÉES

Une protection endommagée doit perdre progressivement son efficacité.

États possibles :

100 % — intacte

Protection normale.

75 % — légèrement endommagée

Petites fissures ou déformations.

50 % — fortement endommagée

Protection réduite, structure compromise.

25 % — critique

Risque élevé de rupture.

0 % — détruite

Protection supprimée du modèle de collision et du système de défense.

Les valeurs exactes peuvent varier selon le matériau et l’équipement.

⸻

37. PRIORITÉ DE RUPTURE

Une rupture ne doit jamais être purement aléatoire.

Elle doit dépendre de :

* puissance du coup ;
* zone touchée ;
* angle ;
* type d’arme ;
* matériau ;
* état antérieur ;
* nombre d’impacts ;
* direction de la force ;
* vulnérabilité de la pièce.

Lorsqu’une pièce atteint son seuil critique, elle peut :

fissurer → se déformer → se détacher → se briser.

La transition doit être visuellement progressive lorsque la nature du matériau le permet.

⸻

38. PRIORITÉ DES ARMES CONTRE ARMES

Lorsqu’une arme rencontre une autre arme, calculer séparément :

arme A → point de contact → arme B.

Comparer leurs caractéristiques :

* matériau ;
* masse ;
* dureté ;
* état ;
* vitesse ;
* angle ;
* force appliquée.

Une arme déjà endommagée doit avoir davantage de risques de rupture.

Le système doit permettre des situations telles que :

épée intacte + épée endommagée → choc → arme endommagée qui se brise.

⸻

39. PRIORITÉ DES BLESSURES

Une fois les protections résolues, calculer les dommages corporels.

La priorité est :

localisation → gravité → type de blessure → saignement → conséquences physiques.

Une blessure ne doit pas automatiquement produire un saignement important.

Le niveau de saignement doit dépendre de la gravité et de la nature de la blessure.

Le système doit également éviter les effets disproportionnés : une petite coupure ne doit pas produire le même volume de sang qu’une blessure majeure.

⸻

40. PRIORITÉ DU SAIGNEMENT

Le système de saignement doit fonctionner indépendamment de la barre de vie.

Calculer :

gravité de la blessure + localisation + état de la blessure + mouvement + temps écoulé

afin de déterminer le débit de saignement.

Le débit doit pouvoir suivre une évolution :

début → augmentation éventuelle → maximum → diminution progressive → écoulement résiduel.

Une nouvelle attaque sur la même zone peut modifier cette courbe.

Une nouvelle blessure doit être enregistrée séparément lorsqu’elle touche une autre zone.

⸻

41. CUMUL DES DÉGÂTS

Les dégâts doivent pouvoir se cumuler.

Exemple :

Impact 1
→ armure fissurée.

Impact 2
→ fissure aggravée.

Impact 3
→ armure fortement déformée.

Impact 4
→ rupture.

Impact 5
→ attaque désormais dirigée directement vers la couche suivante.

Le système doit conserver l’historique des dommages.

⸻

42. PRIORITÉ DES IMPACTS MULTIPLES

Si plusieurs impacts se produisent presque simultanément, le moteur doit les résoudre selon :

1. ordre temporel réel ;
2. localisation ;
3. puissance ;
4. surface de contact ;
5. priorité de collision ;
6. état de la protection au moment exact de l’impact.

Éviter qu’un seul impact soit compté plusieurs fois à cause de collisions successives.

⸻

43. PRIORITÉ DES ZONES VULNÉRABLES

Les équipements doivent posséder des zones présentant des résistances différentes.

Exemple :

casque

* face : protection élevée ;
* visière : protection différente ;
* articulation : protection réduite ;
* fixation : vulnérabilité élevée.

armure

* plastron : protection élevée ;
* épaules : protection intermédiaire ;
* articulations : protection réduite ;
* attaches : vulnérabilité élevée.

Cette logique doit créer un véritable intérêt tactique.

Le joueur expérimenté doit pouvoir exploiter les faiblesses de l’équipement adverse.

⸻

44. PRIORITÉ DES DÉGÂTS SUR LES MEMBRES

Les membres doivent être traités individuellement.

Une attaque sur :

* bras ;
* jambe ;
* épaule ;
* main ;
* torse ;
* tête

doit produire des conséquences différentes.

Un bras fortement blessé peut modifier certaines animations.

Une jambe blessée peut modifier la mobilité.

Une main blessée peut affecter l’utilisation d’une arme.

Ces effets doivent rester progressifs et ne doivent pas transformer instantanément le personnage en combattant incapable d’agir.

⸻

45. PRIORITÉ ENTRE GAMEPLAY ET RÉALISME

Le réalisme doit être prioritaire, mais il ne doit jamais rendre le jeu injouable.

En cas de conflit entre simulation réaliste et gameplay :

1. cohérence physique ;
2. lisibilité ;
3. équilibre compétitif ;
4. spectacle cinématographique.

Les effets spectaculaires ne doivent jamais masquer l’information nécessaire au joueur.

⸻

46. MÉMOIRE DES DÉGÂTS

Chaque combattant possède un Damage State persistant.

Ce système mémorise :

* pièces d’armure détruites ;
* fissures ;
* déformations ;
* armes endommagées ;
* armes cassées ;
* vêtements déchirés ;
* blessures ;
* localisation des blessures ;
* traces de sang ;
* poussière ;
* salissures ;
* fatigue ;
* état des membres ;
* état général du combattant.

Le Damage State doit être sauvegardé pendant toute la durée du combat et, dans le mode tournoi, entre les combats.

⸻

47. RÈGLE ABSOLUE DE COHÉRENCE

Le système doit toujours répondre à la question :

« Qu’est-ce qui a réellement été touché ? »

Avant d’appliquer un quelconque dommage.

Puis :

« Qu’est-ce qui a absorbé l’impact ? »

Puis :

« Quelle énergie a été transmise ? »

Puis :

« Quelle conséquence physique en résulte ? »

Puis :

« Cette conséquence doit-elle rester visible ? »

Cela constitue la chaîne officielle de résolution :

IMPACT → LOCALISATION → PROTECTION → MATÉRIAU → ABSORPTION → TRANSMISSION → DOMMAGE → BLESSURE → SAIGNEMENT → CONSÉQUENCE → PERSISTANCE.

Aucune étape ne doit être ignorée sans justification.

48. RÈGLE DE NON-RÉINITIALISATION

Une fois qu’un dommage physique a été enregistré, il ne doit pas être supprimé arbitrairement.

Détruit = détruit.

Cassé = cassé.

Fissuré = fissuré.

Déchiré = déchiré.

Endommagé = endommagé.

Blessé = blessé.

Sang versé = traces persistantes selon les conditions environnementales.

Le système peut restaurer un personnage uniquement lorsqu’une véritable mécanique narrative ou de gameplay le justifie : soin, réparation, repos, équipement de remplacement ou nouvelle phase explicitement prévue.

OBJECTIF

Le joueur doit pouvoir regarder son personnage à n’importe quel moment et comprendre visuellement son historique de combat.

Le système de dégâts doit transformer chaque affrontement en une simulation persistante de combat, tout en conservant la fluidité, la lisibilité et l’équilibre nécessaires à un jeu vidéo AAA compétitif.
